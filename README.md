# DayRoad

Notion 스타일의 하루 일정 로드맵 플래너입니다. 일정의 시작 시간과 소요 시간을 입력하면 중앙 타임라인에 배치되고, 선택한 일정의 예상 완료 시간과 체크리스트를 확인할 수 있습니다.

## 실행

`index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

로컬 서버로 실행하려면 Python이 있는 환경에서 아래 명령을 사용할 수 있습니다.

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

그 다음 `http://127.0.0.1:4173/index.html`을 열면 됩니다.

## 기능

- 빠른 일정 추가
- 오전, 오후, 저녁 구간별 일정 목록
- 08:00-22:00 세로 시간 로드맵
- 예상 완료 시간과 위험도 표시
- 완료 체크, 집중 모드, 마감 체크리스트
- 목록 보기 전환
- 날짜별 `localStorage` 자동 저장
